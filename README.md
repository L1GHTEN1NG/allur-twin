# ALLUR TWIN

MVP цифрового двойника автомобильного завода для кейса №2 Qostanai AI Industry Hackathon 2026. Показывает состояние производственных участков, потери, события и сценарии влияния простоев.

## Исходный код

[Открыть папку проекта](allur-twin)

## Запуск

Нужен Node.js 20 или новее. Установка зависимостей не требуется.

```sh
cd allur-twin
npm start
```

Откройте http://127.0.0.1:4173. На Windows также можно запустить `start.cmd` из папки проекта.

## Состав проекта

- `allur-twin/dist` — интерфейс цифрового двойника.
- `allur-twin/data` — предоставленные тестовые данные кейса.
- `allur-twin/docs` — описание архитектуры, сценария демонстрации и проверки.
- `allur-twin/tests` — тесты расчётного движка.
- `.github/workflows` — автоматическая проверка и ручная публикация GitHub Pages.

Фактические данные кейса и синтетический демонстрационный поток в интерфейсе помечены отдельно.
