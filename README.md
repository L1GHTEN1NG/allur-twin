MVP цифрового двойника автомобильного завода для кейса №2 Qostanai AI Industry Hackathon 2026 (АЛЛЮР).

## Кратко о MVP

Показывает производственные участки, показатели выпуска и брака, простои, цепочку производства и сценарную симуляцию. Данные кейса отделены от синтетического демонстрационного потока.

**Текущие границы:** реальные датчики/телеметрия, промышленная база данных и AI-модель пока не подключены. Автосводка основана на прозрачных правилах, симуляция — на заданных сценарных параметрах.

Чтобы запустить локально: откройте папку `allur-twin`, установите Node.js 20+ и выполните `npm start`, затем перейдите на `http://127.0.0.1:4173`. Подробности — в [README проекта](allur-twin/README.md).
