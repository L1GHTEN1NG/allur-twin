# Проверка MVP

Проверка выполнена 8 октября 2026 года на локальной версии проекта.

## Расчёты

`node --test tests/engine.test.cjs`: **12 из 12 тестов прошли**.

Проверены исходные значения, фильтрация отклонений, отсутствие двойного счёта автомобилей, геометрия карты и работа с нулевой площадью, выпуск при остановке разных этапов, запасы, сохранение потока, граница смены и монотонность демонстрационных накопленных показателей.

Независимая проверка дополнительно сравнила исходные записи с приложением к кейсу и проверила набор комбинаций параметров модели.

## Браузер

Проверены:

- Загрузка приложения и всех локальных ресурсов.
- Переключение дат: выпуск сборки 121 и 119.
- Карты брака, простоя и выполнения плана, включая доступ к участку с нулём минут.
- Демонстрационный поток с обновлением времени и состояния оборудования; пауза и ручное переключение.
- Карточка выбранного оборудования и производственная цепочка.
- Симуляция: исходный сценарий, нулевой буфер, другой участок.
- Некорректная скорость: сообщение об ошибке, сохранение последнего корректного значения и работа остальных параметров.
- Внешний вид на настольном и узком экране, отсутствие горизонтального переполнения в проверенных представлениях.

## Границы проверки

Workflow GitHub Pages подготовлен по официальным примерам, но не запускался в аккаунте пользователя. Прямое открытие файла без сервера не проверялось: средство проверки браузера допускает только HTTP/HTTPS. Браузерные сценарии проверены через локальный сервер. Реальная телеметрия, серверная база данных и языковая модель в MVP отсутствуют и не тестировались. Фактический промышленный эффект не измерялся.
